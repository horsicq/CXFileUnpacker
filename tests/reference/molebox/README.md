These files reproduce the frozen MoleBox fixtures using original upstream writer functions. They are test references and are not compiled into or distributed with XFU binaries. File names have an added `.txt` suffix to keep source globs from compiling them.

MoleBox upstream commit: `f526e8a41bcb7884231154e8e5ccb74c789f188d` at https://github.com/sudachen/Molebox.
`packager_excerpt.cpp` retains the original `_Packager::Start`, `_WriteContent`, `_GetFullName`, `_WriteNames`, `_WriteFile`, `_WriteDir`, `_UpdateHiddensOnly`, `_AppendInfos`, `_WriteMap`, and `Finish` functions. One error formatter was adapted to return false. `catalog_excerpt.cpp` retains the catalog writer body from `MxbPack/src/pebox.cpp`, wrapped as `MakeCatalog`; one error callback was adapted. The original `Include/layout.h` is unchanged. The RAM adapter replaces upstream stream/string containers, uses Win32 CryptoAPI for MD5, and standard CRC implementations. Fixed compressed streams in `compression.hpp` come from Python standard zlib; the upstream writer chooses compression only if beneficial and performs encryption, tree/header layout and CRC generation itself.

The writer layout requires a Win32 build (`sizeof(void*) == 4`, `sizeof(SPACK_FILE_INFO) == 52`) and two-byte Windows wchar_t. To reproduce, copy the files to a scratch directory with the final `.txt` suffix removed. Compile `main.cpp libhash/src/blowfish.c` using `clang++ -m32 -std=c++17 -D_CRT_SECURE_NO_WARNINGS -ladvapi32`. Invoke `writer OUTPUT FLAGS PASSWORD PREFIX_BOOL CATALOG_BOOL`. FLAGS 0/2/4/6 exercise stored/compressed and raw/encrypted; FLAGS 7 adds hidden filename. The generated payload is 100003 bytes with byte i = (i*17+3)&255. PREFIX_BOOL inserts a harmless 64-byte MZ carrier; no input or packaged program is executed. CATALOG_BOOL appends the upstream internal mount catalog containing MD5(PASSWORD), not the plaintext password.

MoleBox excerpts and adapters are GPL-3.0 test code; full license retained as LICENSE.GPL3. The original xternal Blowfish source/header have their own permissive copyright and permission notices, retained verbatim. The runtime reader is an independent grammar implementation and uses a separately adapted copy of that permissive Blowfish code. Normal regression tests use the frozen vectors and Python's standard library only.

For repeatable proof, run `python reproduce_vectors.py --compiler <clang++.exe> --work <scratch>`. The original `Finish` does not initialize the header's reserved four-byte field. The script therefore excludes ciphertext header offsets 24..47 (the block containing that field and its two CBC successors) when comparing archives; payload blocks, encrypted tree, prior header blocks and catalog must be byte-identical. Native regression verifies every decoded file byte, tree/header grammar, integrity and embedded-key reuse independently against the frozen originals.

`multi_main.cpp` runs the original writer twice against the same RAM stream, then invokes the original catalog writer with two internal package entries and two independent keys. One package has public filenames and the second hidden names; this verifies package prefixes and per-package credentials.
